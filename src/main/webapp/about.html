About This Project

PestGuard AI is a web application that helps farmers identify crop pests from leaf images using an image-classification model trained with Google Teachable Machine.

The system detects the pest, shows how confident the model is, and provides treatment and prevention guidance. Every detection is stored so farmers and administrators can track trends over time.

Tech stack: Java Servlets, JDBC, MySQL, Apache Tomcat, HTML/CSS/JS, and TensorFlow.js via Teachable Machine, built on the MVC architecture.
